# The `mainland-pretty` Package  [![Hackage](https://img.shields.io/hackage/v/mainland-pretty.svg)](https://hackage.haskell.org/package/mainland-pretty) [![Actions Status: haskell-ci](https://github.com/mainland/mainland-pretty/actions/workflows/haskell-ci.yml/badge.svg)](https://github.com/mainland/mainland-pretty/actions?query=workflow%3Ahaskell-ci)

A pretty-printing library for source code, based on Wadler's
*A Prettier Printer*. It supports width-sensitive layout, source location
tracking with optional `#line` directives, and output to String or lazy Text.

See the [API documentation](https://hackage.haskell.org/package/mainland-pretty/docs/Text-PrettyPrint-Mainland.html)
for usage and examples, and the
[changelog](https://hackage.haskell.org/package/mainland-pretty/changelog) for
release notes.

See [CONTRIBUTING.md](https://github.com/mainland/mainland-pretty/blob/main/CONTRIBUTING.md)
for development and testing instructions.

## AI assistance

All contributions included in releases through version `0.7.1.1` were made
without AI assistance. AI tools were used in development, review, and release
preparation after that version, through version `1.0.0`. The maintainer remains
responsible for this release.
